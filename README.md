# Fun Loading Message with CSS Animation

This is a simple HTML and CSS code snippet that displays a loading message with a rotating animation. When you view it in a web browser, you'll see a message along with a loading animation.

## How to Use

1. Copy the HTML code into your HTML file.
2. Copy the CSS code into your CSS file (`style.css` in this case).
3. Ensure both files are in the same directory.
4. Open the HTML file in a web browser to see the loading message and animation.
